# YouTube-Shorts-Big-Subtitles
markdown# YouTube Shorts Big Subtitles 📺💥

Простое и легковесное расширение для браузеров на базе Chromium (Google Chrome, Яндекс.Браузер, Edge, Opera), которое **принудительно увеличивает системные субтитры в YouTube Shorts** на ПК.

YouTube часто делает субтитры в Shorts крошечными (около 11px), из-за чего их невозможно читать с монитора. Это расширение перехватывает стили плеера (включая скрытые iframe-фреймы) и делает текст крупным, жирным и читаемым.

## ✨ Особенности
* 📏 **Большой размер:** Увеличивает шрифт до комфортных `32px`.
* 🖤 **Супер-читаемость:** Добавляет полупрозрачный темный фон и четкую двойную тень, чтобы белые буквы не сливались со светлыми кадрами.
* 🛠 **Обход ограничений:** Работает в Manifest V3 и проникает внутрь изолированных фреймов плеера (`all_frames: true`), что не всегда под силу обычному Tampermonkey.

## 🚀 Инструкция по установке

Поскольку расширение создано вручную для личного использования, оно устанавливается в режиме разработчика всего за 1 минуту:

1. **Скачайте файлы** (или создайте папку `BigSubs` у себя на компьютере). В папке должно быть три файла: `manifest.json`, `style.css` и этот `README.md`.
2. Откройте браузер (например, Google Chrome) и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
3. В правом верхнем углу экрана включите тумблер **«Режим разработчика»** (Developer mode).
4. В левом верхнем углу нажмите появившуюся кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите вашу папку `BigSubs`.

*Готово! Расширение появится в списке. Теперь можно открыть любые Shorts на YouTube, включить субтитры (кнопка CC) и наслаждаться крупным текстом.*

## 🔧 Как изменить размер или цвет шрифта под себя?

Вы можете в любой момент настроить внешний вид субтитров:
1. Откройте файл `style.css` через любой текстовый редактор (Блокнот).
2. Найдите строку `font-size: 32px !important;` и замените `32px` на любой нужный вам размер (например, `28px` или `38px`).
3. Сохраните файл (`Ctrl + S`).
4. Зайдите обратно на страницу `chrome://extensions/` и нажмите **значок круговой стрелки (Обновить)** на карточке расширения «YouTube Shorts Big Subtitles».
5. Обновите страницу с видео на YouTube.
